# KIR の経路(test/dune の別名 runtest-via-ir)で、木の評価器のまま走らせるコマンドの一覧。
# 各行は「ファイル名:行番号 理由」で、行番号は .t の中の `  $ ` の行である。
# 載せたコマンドも走らせて期待値と比べるが、DIKTOR_VIA_IR を 0 に戻して走らせる。
# 後のコマンドが、載せたコマンドの作ったファイルや出力を使うことがあるからである。
#
# 理由は 2 種類ある。
# - stack: OCAMLRUNPARAM=l=... で OCaml のスタックの上限を絞るコマンド。
#   木の評価器のスタックの限度を試すもので、KIR の評価器は論理的な深さで限度を数えるので、
#   この経路の比較の対象にしない(恒久の除外)。
# - handle: 評価が handle に届くコマンド。KIR の評価器がまだ handle を評価できず、
#   「未実装」の 4 で終わるので、一時的に除外する。handle を評価できるようになったら消す。
#   stack と handle の両方にあたるコマンドは、stack として載せ、理由に handle も書く。
