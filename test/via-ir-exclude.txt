# KIR の経路(test/dune の別名 runtest-via-ir)で、木の評価器のまま走らせるコマンドの一覧。
# 各行は「ファイル名:行番号 理由」で、行番号は .t の中の `  $ ` の行である。
# 載せたコマンドも走らせて期待値と比べるが、DIKTOR_VIA_IR を 0 に戻して走らせる。
# 後のコマンドが、載せたコマンドの作ったファイルや出力を使うことがあるからである。
#
# 理由は stack の 1 種類である。
# - stack: OCAMLRUNPARAM=l=... で OCaml のスタックの上限を絞り、
#   木の評価器がその上限でスタックオーバーフローになることを期待値にしたコマンド。
#   KIR の評価器は論理的な深さで限度を数え、末尾でない再帰の段の数では OCaml のスタックの上限に届かないので、
#   同じコマンドが最後まで走る。
#   この経路の比較の対象にしない(恒久の除外)。
# OCAMLRUNPARAM でスタックを絞るほかのコマンド(末尾呼び出しと末尾 resume が一定の領域で走ることを確かめるもの)は、
# KIR の評価器でも同じ期待値になるので、除外しない。
