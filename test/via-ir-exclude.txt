# KIR の経路(test/dune の別名 runtest-via-ir)でも、構文木の評価器で実行するコマンドの一覧である。
# 各行は「ファイル名:行番号 理由」の形式で、行番号は .t の中の `  $ ` の行の番号である。
# 一覧に載せたコマンドも実行して期待値と比較するが、そのコマンドの間だけ DIKTOR_VIA_IR を 0 に戻す。
# 後のコマンドが、載せたコマンドの作ったファイルや出力を使うことがあるからである。
#
# 理由は stack の 1 種類だけである。
# - stack: OCAMLRUNPARAM=l=... で OCaml のスタックの上限を小さくし、
#   構文木の評価器がその上限でスタックオーバーフローになることを期待値にしたコマンド。
#   KIR の評価器は再帰を論理的な深さで数えて制限するので、これらのコマンドの再帰の段数では OCaml のスタックの上限に達せず、
#   同じコマンドが最後まで実行される。
#   KIR の評価器の結果は期待値と一致しないので、KIR の評価器での実行から恒久的に除外する。
# OCAMLRUNPARAM でスタックを小さくするほかのコマンド(末尾呼び出しと末尾 resume でスタックが増えないことを確かめるもの)は、
# KIR の評価器でも同じ期待値になるので、除外しない。
